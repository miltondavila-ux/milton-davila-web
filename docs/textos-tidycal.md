Las descripciones sirven para cualquier sector. Si alguna sesión es por videollamada, cambia la palabra "llamada".

## 1. Sesión de 10 minutos
Enlace: https://tidycal.com/miltondavila/10-minutos-con-milton-davila

**Nombre del evento**
```
Conversación de 10 minutos con Milton Dávila
```

**Descripción**
```
Una llamada corta para contarme qué está frenando tu negocio y ver si puedo ayudarte.

Sirve para:
• Resolver una pregunta puntual.
• Saber por dónde empezar.
• Ver cuál sería el siguiente paso.

Para aprovecharla: antes de la llamada, escribe en una frase a qué se dedica tu negocio y qué quieres resolver.

Sin costo.
```

## 3. Sesión de 60 minutos
Enlace: https://tidycal.com/miltondavila/consulta-1-hora-con-milton

**Nombre del evento**
```
Sesión de estrategia de 60 minutos con Milton Dávila
```

**Descripción**
```
Una hora de trabajo a fondo para revisar tu negocio y salir con pasos concretos.

Revisamos juntos:

Para aprovecharla: antes de la sesión, cuéntame a qué se dedica tu negocio, qué herramientas usas hoy (CRM, correo, página web) y qué quieres lograr.

Para empresas, profesionales y negocios de cualquier sector.
```
